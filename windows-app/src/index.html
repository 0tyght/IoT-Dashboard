เริ่มใช้งาน VECTRA

  1. ต่ออุปกรณ์ จ่ายไฟเซ็นเซอร์ตามคู่มือ แล้วต่อ RS485 A/B ผ่าน USB Adapter ไปยังคอมพิวเตอร์
  2. เพิ่มมอเตอร์ เลือกพอร์ต รุ่นเซ็นเซอร์ Slave ID และค่าการสื่อสารที่ตรงกับอุปกรณ์ ทดสอบทีละตัวก่อนเริ่ม หากอยู่บัสเดียวกันแต่ละตัวต้องใช้ Slave ID ไม่ซ้ำ
  3. เริ่มอ่านและบันทึก กดปุ่มหลักครั้งเดียว โปรแกรมตรวจทุกมอเตอร์แล้วเริ่มอ่านและบันทึกอัตโนมัติ กดหยุดเพื่อจบรอบและรอเขียนไฟล์ให้เสร็จ
  4. เปลี่ยนโหมดเมื่อจำเป็น ขณะหยุด เลือกดูอย่างเดียวหรือตั้งเวลาได้จากปุ่มโหมด เมนูเพิ่มเติมมีคำสั่งหยุดบันทึกแต่ยังอ่านต่อ และเริ่มบันทึกทันที
  5. ดูประวัติ / ส่งออก เลือกวันและมอเตอร์ได้จากแท็บประวัติ CSV ส่งออกข้อมูลทั้งหมดของตัวกรองนั้น เปิดไฟล์จริงได้จาก เพิ่มเติม → เปิดโฟลเดอร์ข้อมูล
  6. ตรวจค่าบนกราฟ กล่องด้านซ้ายแสดงค่าของกราฟนั้น ชี้กราฟเพื่อเทียบเวลา ชี้เมนูค่าดิบและสูตรเพื่อดูรายละเอียด กดเพื่อตรึงข้อมูลเวลานั้น และกด Escape เพื่อปิด

ระหว่างบันทึก ข้อมูลจริงเก็บเป็น CSV รายวันในเครื่อง พร้อมเวลา UTC และ UTC+07:00 · โหมดทดลองแสดงข้อมูลจำลองและไม่เขียนลงประวัติจริง · ปุ่มพักกราฟหยุดเฉพาะกราฟ · ตั้งเวลาไม่ปลุกเครื่องและต้องเริ่มอ่านข้อมูลไว้แล้ว

หากอ่านไม่สำเร็จ ตรวจไฟเลี้ยง สาย A/B, Slave ID และ Baud rate โปรแกรมจะลองอ่านใหม่อัตโนมัติ สีสถานะหมายถึงคุณภาพการสื่อสาร ไม่ใช่ความรุนแรงการสั่น

Frequency อ่านค่าดิบได้ แต่ต้องยืนยันลำดับ Float ก่อนแสดง Hz · การสอบเทียบยังไม่เปิดให้เขียนค่า
