เริ่มใช้งาน VECTRA

  1. ต่ออุปกรณ์ จ่ายไฟเซ็นเซอร์ตามคู่มือ แล้วต่อ RS485 A/B ผ่าน USB Adapter ไปยังคอมพิวเตอร์
  2. เพิ่มมอเตอร์ เลือกพอร์ต รุ่นเซ็นเซอร์ Slave ID และค่าการสื่อสารที่ตรงกับอุปกรณ์
  3. ทดสอบและบันทึก ทดสอบทีละตัวก่อนเริ่มอ่าน หากอยู่บัสเดียวกันแต่ละตัวต้องใช้ Slave ID ไม่ซ้ำ
  4. เริ่มอ่านข้อมูล โปรแกรมอ่านมอเตอร์ตามลำดับบนแต่ละบัส ทดสอบครบทุกตัวก่อนเปิดการบันทึก
  5. ดูประวัติ / ส่งออก เลือกวันและมอเตอร์ได้จากแท็บประวัติ CSV ส่งออกข้อมูลทั้งหมดของตัวกรองนั้น

ข้อมูลจริงเก็บเป็นไฟล์ NDJSON รายวันในเครื่อง · โหมดทดลองแสดงข้อมูลจำลองและไม่เขียนลงประวัติจริง · ปุ่มพักกราฟหยุดเฉพาะการแสดงผล

หากอ่านไม่สำเร็จ ตรวจไฟเลี้ยง สาย A/B, Slave ID และ Baud rate โปรแกรมจะลองอ่านใหม่อัตโนมัติ สีสถานะหมายถึงคุณภาพการสื่อสาร ไม่ใช่ความรุนแรงการสั่น

Frequency register และการสอบเทียบยังไม่เปิดใช้ เพราะคู่มือที่ได้รับยังไม่ยืนยันรูปแบบ Floating Point และลำดับ word
