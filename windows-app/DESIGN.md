# Windows monitoring interface

Scope: `windows-app/src`. The repository-root website is a separate application.

The supplied white and violet vibration-dashboard reference (`codex-clipboard-1310d809-2def-4225-b2c6-a02d1c04b72f.png`) defines the visual world. Keep acquisition, recording, motor management, timestamps and history. The current monitoring workspace fits three vibration plots and all numerical channels in one viewport, with a quiet slate registry providing contrast. The user explicitly excludes the 3D model from this dashboard; it belongs to a separate lazily loaded 3D tab. Use direct Thai product language without slogans.

## Palette and surfaces

- Workspace `#f7f8fb`; white panels and navigation; body text `#414657`, muted text `#6b7180`; thin dividers `#e5e7ef`.
- Primary action and active selection `#6252e9`, hover `#4f3dd2`; pale lavender selection `#f2f0ff`. Purple indicates action and navigation, not motor condition.
- Axis X `#007b8d`, Y `#3474bb`, Z `#6750c5`. Shared CSS variables drive numerical text, legends and plotted lines. Colors separate axes, never severity.
- Charts use grid `#e9ecf3`, readable labels `#6d7384` and cursor `#8c80ca`. Plot colors derive from theme tokens; no dark-theme paint remains in SVG attributes.
- Green communicates receiving/saving; red communicates a fault; simulation stays explicitly labelled. Pale backgrounds support those labels without coloring whole motor headers.
- Panel radius 9–10 px; light borders and a restrained offset shadow follow the supplied reference. Controls stay rectangular, with a consistent authored SVG icon vocabulary.

## Layout and interaction

- White header and one primary session action: Start while idle, Stop while running. The button's label describes the selected mode. A compact status strip appears during a session or to show its saved result; hide it on a fresh idle screen. Motor registry on the left; violet active tabs and a collapsible registry.
- Overview, detail and history show three plots in a single vertical column: velocity, displacement and acceleration, each with X/Y/Z and independent units. Every plot spans the available width. Temperature is numerical only. Frequency X/Y/Z is numerical with its own quality/format explanation; no selector hides measured axes.
- Each graph owns a left-hand value box with its axis values, units, sample time and raw/formula inspector. Pointer and keyboard time selection update all three boxes together. Overview no longer duplicates the nine vibration values above charts. In the monitor, three rows divide the remaining height equally and the value boxes stay beside their charts; compact charts reduce tick count without scaling down text. Other chart containers below 580 px can stack values above plots.
- Hover opens raw/formula details; click or Enter pins a timestamped snapshot for reading/copying; Escape closes it. Per-axis hover text also exposes the conversion. Show zero-based addresses, decimal/hex words, signed interpretation, divisor or custom type/order/scale and recorded result. Never reconstruct missing raw data. New custom readings store their decoding configuration alongside NDJSON so history does not apply a later profile's settings. Legacy custom data explicitly reports missing formula metadata. Simulation is identified and quantized consistently with its mock raw words.
- Motor details give most of the viewport to the graphs, with temperature, frequency X/Y/Z and acquisition status in a compact context rail. Full channel data/nameplate opens in a floating panel. Portrait tablet layouts move compact telemetry above full-width plots. A context toggle expands chart width; one/five/thirty-minute shortcuts change the actual time window. Below 1180 px the registry opens as an overlay drawer, automatically closed when entering the monitor. Desktop/tablet monitor targets are 960×680, 1366×768, 1920×1080, 1024×768 and 768×1024, all without scrolling the main view.
- Keep V4 exclusively in its own 3D page. It remains explicitly unassociated with physical motors or sensor positions. Fullscreen model and fullscreen plots have an exit action and Escape support; three fullscreen plots share available height equally.
- The self-contained model is isolated in an iframe with scripts only, no parent origin or application API access. Rotation, zoom, pan, preset cameras and reset are available. A real asset poster and retry action handle WebGL failure. Loading is deferred until the separate 3D tab is opened; no network runtime is required.
- Frequency words are read separately so unsupported frequency registers do not discard the nine primary vibration values. The default unconfirmed Float order shows raw words and blank Hz; only an explicitly selected format enables conversion. Keep errors, old records and simulated frequency visibly distinct.
- Segoe UI/Tahoma supports Windows and Thai. Controls and main labels 12–13 px, auxiliary metadata at least 11 px. Use tabular figures; SVG axes stay 11 rendered pixels on resize.
- Visible focus, text-labelled actions, 32 px minimum motor actions, keyboard tabs with arrows/Home/End and standard Windows inputs. Dialog motion lasts 150 ms and respects reduced motion.
- Default to a single “เริ่มอ่านและบันทึก” command: validate motors, acquire and record. “หยุดอ่านและบันทึก” disconnects and drains file writes. The mode button offers automatic recording, explicit monitor-only or scheduled recording with optional duration. Legacy manual-start settings follow the new combined Start action; existing explicit monitor-only settings stay read-only. No background recording starts without the user pressing Start.
- Keep the advanced separation available under “เพิ่มเติม”: start recording immediately or stop recording while monitoring continues, open the data folder and run simulation. Close the menu on selection, outside click or Escape; preserve keyboard access. Disable competing operations while file/connection actions are pending.
- Duration completion stops recording and keeps monitoring, explicitly labelled. Past schedules open settings before connection; a schedule missed during sensor verification is reported with a direct recovery action. Show saved count/last successful write and storage errors, not a generic green saved claim.
- Remove duplicate Add buttons from overview and registry toolbars; keep the global Add action and empty-state guidance. One global simulation status replaces repeated view banners. Settings/help describe user tasks rather than internal NDJSON storage.
- Dynamic chart windows explain bounded live retention; history loads recorded timestamp ranges. Never label 10–5000 Hz vibration bandwidth as update rate, or infer bearing faults/ISO zones from communications status.
- Time cursors and keyboard navigation synchronize across a motor's plots. Readouts retain each graph's unit and scale; temperature is not a spatial axis. Gaps exceeding three requested poll periods break the trace only when original samples are available. Reduced historical data explicitly disables gap inference. Offscreen overview charts defer drawing while acquisition and storage continue.
- Hover/focus on an axis emphasizes its matching traces across all three plots while keeping every axis present; keyboard focus takes priority over hover. Native popovers avoid clipping in the bounded workspace and close on Escape, outside click, tab changes or context changes. Escape closes an inspector before leaving fullscreen, including when focus is in the 3D iframe. Reduced motion disables decorative transitions. Functional compact text has an 11 px floor; raw detail panels remain 12 px.
- Custom registers show one plot in their configured unit. Small nonzero values use scientific notation instead of rounding to zero. Changing historical motor/time filters clears the previous curve. Event timestamps include the date, milliseconds and UTC+07:00.
- Keep the main monitor in 2D. The supplied registers do not establish synchronized waveforms or spectra; do not fabricate an orbit, FFT or waterfall from these overall readouts. A future diagnostic view needs the appropriate measured source data first.

Validate empty, receiving, simulated, stopped, paused, fault/stale, recording, monitor-only, storage failure and maintenance states across 960×680, 1366×768 and 1920×1080. Visual reference content is style evidence; unsupported fault scores, RMS labels and thresholds in that image are not new measurements or product capabilities.
