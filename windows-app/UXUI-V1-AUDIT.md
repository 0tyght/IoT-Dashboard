# VECTRA — UX/UI ก่อนรุ่น 1.0

ตรวจวันที่ 6 พฤศจิกายน 2026 · ซอร์ส 0.30.7 · ข้อเสนอสำหรับพัฒนา ยังไม่ได้เปลี่ยนหน้าจอหรือปล่อยรุ่น 1.0

## ผลประเมิน

ควรแก้โครงสร้างการใช้งานก่อนปรับสีหรือเพิ่มลูกเล่น เมนูหลักปัจจุบันนำงานระดับพื้นที่งาน ระดับอุปกรณ์ และระดับข้อมูลย้อนหลังมาเรียงเท่ากัน ผู้ใช้จึงต้องจำเองว่าตัวเลือกด้านซ้ายมีผลต่อหน้าใด และการกดตั้งค่าหรือเริ่มอ่านจะทำกับรายการใด

พื้นฐานที่ควรเก็บ: อุปกรณ์ใช้รูปแบบรายการและฟอร์มร่วมกัน, แผนผังอุปกรณ์ → บัส → เครื่องรับข้อมูล, ปุ่มเริ่มอ่านพร้อมบันทึก, แม่แบบไม่เก็บ Slave ID, สถานะมีข้อความประกอบสี, ฟอร์มมีปุ่มทดสอบ/บันทึกติดขอบล่าง และมีการเตือนก่อนละทิ้งการแก้ไข

## ขอบเขตและหลักฐาน

- เปิด Electron จากซอร์สปัจจุบันด้วยโฟลเดอร์ข้อมูลตรวจแยกต่างหาก ตั้งชื่ออุปกรณ์สั่น 2 ตัวและ PM2230 1 ตัวเพื่อทบทวนบริบท ไม่มีการเริ่มอ่านพอร์ตหรือสร้างค่าการวัดจำลอง
- ตรวจทั้ง 8 เมนูหลัก พร้อมหน้าสร้างพื้นที่งาน ตั้งค่าอุปกรณ์ โหมดบันทึก เมนูเพิ่มเติม Custom Register และการเตือนค่าที่ยังไม่บันทึก
- ภาพหน้าต่างจริง 1426×933 และ 931×713 พิกเซล รวมขอบหน้าต่าง Windows; ภาพ 931×933 แสดงช่วงเปลี่ยนเป็นเมนูแนวนอนด้วย ขนาดนี้ไม่ใช่การยืนยันว่าทดสอบ viewport 1366×768 แล้ว
- ภาพในรายงานเป็นหน้าจอปัจจุบันทั้งหมด ไม่ใช่ภาพแบบหน้าจอใหม่ รายการภาพและ SHA-256 อยู่ใน `.artifacts/ux-v1-audit/screenshots.json`
- ไม่ใช้ภาพเก่าหรือผลทดสอบรุ่นก่อนแทนหลักฐานรอบนี้

## โครงสร้างที่เสนอ

เมนูหลักใช้ 3 กลุ่มงาน และปุ่มตั้งค่าส่วนกลางที่มีชื่อชัดเจน เมนูย่อยแสดงภายในบริบทที่กำลังเลือก

```text
พื้นที่งาน
  เลือก / สร้างพื้นที่งาน
  ภาพรวมและแผนผัง — อุปกรณ์ บัส และเครื่องรับข้อมูล
  ค่าที่อ่าน — ภาพรวมทุกอุปกรณ์ / รายละเอียดอุปกรณ์ที่เลือก
    ค่าการวัดและกราฟ
    ค่าดิบและสูตร (Register)
    ตั้งค่าอุปกรณ์
  มุมมอง 3D — หน้าแยก เปิดใช้เมื่อพื้นที่งานมีโมเดลที่กำหนดไว้

รอบบันทึก
  รายการรอบ — ชื่อ เวลา พื้นที่งาน จำนวนอุปกรณ์ สถานะไฟล์
  เลือกรอบ
    สรุปและคุณภาพข้อมูล
    ตาราง / กราฟเวลา / วิเคราะห์
    ไฟล์ CSV และเหตุการณ์ของรอบ
  นำเข้าไฟล์วิเคราะห์ — แสดงแหล่งข้อมูลและข้อกำหนดก่อนเลือกกราฟ

คลัง
  อุปกรณ์ทั้งหมด
  แม่แบบ Register

ตั้งค่าโปรแกรม
  การจัดเก็บ / สำรองและกู้คืน / การวินิจฉัย / คู่มือและเวอร์ชัน
```

การวิเคราะห์ไม่ควรบังคับให้มีรอบบันทึกก่อนนำเข้าไฟล์ภายนอก แต่เมื่อเปิดจากรอบบันทึก ให้ส่งรอบ อุปกรณ์ ช่วงเวลา และหน่วยไปด้วยทั้งหมด และมีปุ่มกลับรอบเดิม

### เจ้าของข้อมูลและการตั้งค่า

| รายการ | อยู่ที่ใด / ผลเมื่อเปลี่ยน |
| --- | --- |
| พื้นที่งาน | กำหนดอุปกรณ์ที่อ่านร่วมกันและมุมมองของชุดงาน |
| บัส | COM, Baud, Parity, Stop bits และช่วงเว้นระหว่างอุปกรณ์ ตั้งที่โหนดบัส; ในฟอร์มอุปกรณ์แสดงสรุปและลิงก์ไปบัสเดียวกัน |
| อุปกรณ์ | ชื่อ รหัส Slave ID บัสที่สังกัด ระยะอ่าน Timeout และผังค่าที่อ่าน; การตั้งค่าต้องระบุอุปกรณ์เจ้าของเสมอ |
| แม่แบบ Register | Address, Function, ชนิดข้อมูล, Byte/Word order, สูตร และหน่วย; ไม่เก็บชื่ออุปกรณ์ COM หรือ Slave ID |
| รอบบันทึก | อุปกรณ์และการตั้งค่า ณ เวลารัน เวลาเริ่ม/จบ ไฟล์ และคุณภาพข้อมูล; การแก้ค่าปัจจุบันไม่เปลี่ยนความหมายของรอบเก่า |
| โปรแกรม | ตำแหน่งข้อมูล สำรอง/กู้คืน และความต้องการของเครื่องนี้ |

หัวหน้าจอควรอ่านได้เป็น “พื้นที่งาน › อุปกรณ์ › ค่าดิบและสูตร” หรือ “รอบบันทึก › ชื่อรอบ › วิเคราะห์” และคงชื่อจริงที่มองเห็นได้ การเลือกอุปกรณ์สดต้องไม่เปลี่ยนตัวกรองรอบย้อนหลังโดยเงียบ ๆ

## ลำดับพัฒนา

1. ปิดกติกาข้อมูลและขอบเขตคำสั่ง: พื้นที่งาน อุปกรณ์ บัส แม่แบบ รอบบันทึก; ทำ U01–U05 ก่อน และทดสอบข้อมูลเดิมโดยไม่เปลี่ยนรหัสบันทึกเก่า
2. เปลี่ยน Navigation และหัวบริบท พร้อมย้ายเครื่องมือไปยังเจ้าของงาน คงระบบอ่านพอร์ตและไฟล์เดิมไว้ระหว่างย้าย UI
3. รวมประวัติเป็นรายการรอบเดียวและส่งบริบทไปวิเคราะห์ ใช้ช่องวัดและหน่วยเป็นข้อมูลกลาง รองรับอุปกรณ์หลายชนิดและผัง Custom
4. ปรับฟอร์มและตารางให้กระชับ ยุบส่วนพอร์ต/ขั้นสูง เพิ่มพื้นที่ Register แก้คำสั่งลบ/นำออก/ละทิ้งให้ตรงผลจริง
5. ทดสอบกระบวนการจบรอบจนไฟล์พร้อม สำรอง/กู้คืน ความผิดพลาด และการเปิดซ้ำ แล้วจึงตรวจภาพ สี Focus และการเคลื่อนไหวรอบสุดท้าย

## เกณฑ์ผ่านก่อนปล่อย 1.0

### เส้นทางหลัก

- เริ่มจากข้อมูลว่าง → สร้างพื้นที่งาน → เพิ่มบัส → เพิ่มอุปกรณ์จากแม่แบบ/Custom → กำหนด Slave ID → ทดสอบ → เริ่มอ่านและบันทึก → หยุดและรอไฟล์พร้อม → เปิดรอบนั้นในโปรแกรม → ดูตาราง กราฟ และ CSV แยกอุปกรณ์ได้
- ทำเส้นทางเดียวกันด้วยเซ็นเซอร์ 2 ตัวและ PM2230 1 ตัวบนบัสร่วม รวมถึงอุปกรณ์ Custom ที่มีหลายจุดวัด ทุกหน้าต้องแสดงชื่อและหน่วยตรงกัน
- เปิดย้อนหลังแล้วไม่เปลี่ยนอุปกรณ์สด ไม่เริ่มการอ่านพอร์ต และกลับรอบเดิมโดยยังคงตัวกรอง
- สำรองและกู้คืนการตั้งค่าครบทุกชนิดอุปกรณ์บนโฟลเดอร์ใหม่ ทดสอบจำนวนอุปกรณ์ แม่แบบ บัส พื้นที่งาน และการผูกกัน ไม่ทดสอบบนไฟล์ใช้งานจริง
- การนำออกจากพื้นที่งาน การลบจากคลัง และการแก้แม่แบบมีผลตามชื่อคำสั่ง พร้อมแสดงผลกระทบต่อพื้นที่งานอื่นและข้อมูลเก่า

### สถานะและข้อผิดพลาด

- แยกส่งคำขอ/ตอบกลับ/Timeout ออกจากค่าที่ตีความไม่ได้ ข้อมูลเก่า และเขียนไฟล์ไม่สำเร็จ การตอบ Modbus สำเร็จไม่เท่ากับทุกค่าถูกต้องหรือเครื่องจักรปกติ
- ทดสอบ COM หาย, Slave ID ซ้ำ, บัสตั้งค่าไม่ตรง, ข้อมูลตอบบางส่วน, Float ยังไม่ยืนยัน, พื้นที่เก็บข้อมูลเต็ม, ปิดโปรแกรมระหว่างรัน และการกลับมาทำต่อ/เปิดไฟล์หลังผิดพลาด
- ระหว่างจบการบันทึกต้องแสดงกำลังเขียนไฟล์ ห้ามแสดงว่า CSV พร้อมก่อนงานเขียนเสร็จ และข้อผิดพลาดต้องระบุอุปกรณ์ รอบ และวิธีแก้
- FFT ค่ารวมระบุอัตราตัวอย่างจากเวลาที่รับและข้อจำกัดของข้อมูล ส่วน FFT คลื่นดิบต้องมี Waveform และ Sample rate ที่ยืนยัน ห้ามใช้กราฟสวยแทนข้อมูลที่ไม่มี

### หน้าจอและการเข้าถึง

- ทดสอบใหม่ที่ 1280×720, 1366×768, 1920×1080, 960×680 และ 768×1024 รวม Windows scaling 100/125/150% และ Zoom 200% โดยวัดพื้นที่เนื้อหาที่ได้จริง
- เป้าหมายหน้าติดตามคือกราฟหลัก 3 แถวและค่าของแต่ละกราฟอยู่ด้วยกัน ส่วนตาราง/รายชื่อจำนวนมากใช้ค้นหา แบ่งหน้า และขยายพื้นที่ได้ ไม่ย่อข้อความเพื่อฝืนใส่ทุกแถว
- เมนูย่อยมีรูปแบบเดียวกัน ใช้คีย์บอร์ดเข้าถึงได้ Focus ชัด กลับจาก Dialog มาที่ปุ่มต้นทางได้ Tooltip ไม่ใช่ทางเดียวที่อ่านข้อมูลสำคัญ
- ตรวจ Contrast จากสีที่คำนวณจริง ทดสอบ Screen reader และ Touch เพิ่มเติม ภาพหน้าจอเพียงอย่างเดียวไม่ยืนยัน WCAG หรือการใช้งาน iPad จริง
- การเคลื่อนไหวสั้นและมีหน้าที่ เช่น เปิด Drawer/ยืนยันบันทึก เคารพ Reduce motion; สีม่วงเน้นการเลือก สีแกน X/Y/Z คงเดิม สถานะสื่อสารใช้เทา/เหลือง/เขียว/แดงพร้อมข้อความ

## ข้อจำกัดของผลตรวจรอบนี้

ไม่ได้รันทดสอบฮาร์ดแวร์จริง ไม่ได้ทดสอบความถูกต้องเชิงตัวเลขของกราฟที่มีข้อมูลเต็ม การทำงาน Waveform/FFT ทุกแบบ การเขียน CSV รอบใหม่ การกู้คืนหลัง Crash การสำรอง/นำเข้าแบบกดจริง หรือ Screen reader ทั้งระบบ รายการเกณฑ์ผ่านด้านบนจึงเป็นงานที่ยังต้องยืนยัน ไม่ใช่รายการที่ผ่านแล้ว ภาพ Custom Register แสดงพฤติกรรมการเลื่อนที่พบจริง ไม่ใช่ภาพตารางทั้งหมดในจอเดียว

รอบนี้เปลี่ยนเฉพาะเอกสารตรวจและหลักฐานประกอบ ไม่มีการแก้ระบบอ่าน Modbus เปลี่ยนข้อมูลผู้ใช้ หรือเพิ่มเวอร์ชันโปรแกรม
