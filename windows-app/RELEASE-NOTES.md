## VECTRA Sensor Monitor 0.32.0

- จัดเมนูหลักใหม่: พื้นที่งาน / รอบบันทึก / คลัง / ตั้งค่า พร้อมเมนูย่อยตามบริบท
- รายละเอียดอุปกรณ์รวมค่าการวัดและค่าดิบ/สูตร กราฟการสั่น 3 แถวยังแสดงครบ และหน้าภาพรวมมีตัวเลือกช่วงกราฟของตัวเอง
- รวมข้อมูลทุกชนิดอุปกรณ์ในรายการรอบบันทึกเดียว เปิดตาราง กราฟเวลา คุณภาพ และเหตุการณ์ของรอบเก่าในโปรแกรมได้ แม้ไม่มีอุปกรณ์นั้นในพื้นที่งานปัจจุบัน
- เลือกคอลัมน์ตาราง ดูค่าดิบ/สูตรตามเวลาที่บันทึก และส่งรอบ/อุปกรณ์/ช่วงเวลาไปวิเคราะห์ได้ โดยไม่เปลี่ยนตามการเลือกอุปกรณ์สด
- แยกนำออกจากพื้นที่งานกับลบจากคลัง และเก็บการตั้งค่ามิเตอร์ที่นำออกไว้ใช้ซ้ำ
- สำรอง/กู้คืนครบอุปกรณ์ทุกชนิด พื้นที่งาน บัส แม่แบบ และโหมดบันทึก พร้อมตรวจไฟล์ สำเนาก่อนแทนที่ และคืนไฟล์เดิมหากกู้คืนสะดุด
- ปรับฟอร์ม Register พื้นที่แก้ไขขยายได้ ยุบรายการพอร์ตบนจอเล็ก และระบุเจ้าของการตั้งค่า
- เหตุการณ์กรองตามอุปกรณ์/รอบ/ระดับได้ Badge นับเฉพาะข้อผิดพลาด และมีปุ่มไปยังอุปกรณ์ที่เกี่ยวข้อง

Windows x64: มีทั้งตัวติดตั้งและ Portable ข้อมูลการวัดและผัง Register เดิมยังใช้ได้ ระบบคิว Modbus/RS485 เดิมไม่ได้เปลี่ยนในรุ่นนี้

รุ่นเตรียม 1.0: ผลทดสอบซอฟต์แวร์ใช้ข้อมูลทดสอบแยกจากข้อมูลผู้ใช้ ไม่ใช่การยืนยันการสอบเทียบเซ็นเซอร์หรือเสถียรภาพฮาร์ดแวร์ระยะยาว ควรตรวจร่วมกับอุปกรณ์จริงก่อนกำหนดเป็นรุ่น 1.0
